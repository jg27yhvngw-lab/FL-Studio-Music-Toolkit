نسخة تجريبية أولى: اختر السلم والكوردات، شاهد النوتات بالأسماء، ثم نزّل ملف MIDI واستورده إلى FL Studio.

اختر 4 كوردات بالترتيب. يمكنك تعديل كل خانة قبل تصدير MIDI.

الكوردات والنوتات

التصدير الحالي ينشئ MIDI متعدد التراكات، كورد واحد في كل تراک، مع مدة الكورد حسب عدد الـBars المختار.

طريقة الاستخدام في FL Studio

  1. اضغط «تنزيل MIDI» واحفظ الملف.
  2. اسحب ملف MIDI إلى Playlist في FL Studio، أو استخدم File → Import → MIDI file حسب إصدارك.
  3. اختر الآلات الصوتية وعدّل الـVoicing والـVelocity حسب إحساس الأغنية.
